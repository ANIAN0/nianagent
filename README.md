# Moon

本地 agent 应用，使用 React、Vite、shadcn/ui 和 Tauri。工作区、模型与会话配置保存于本机；对话和工具执行由 Pi SDK 提供。

## 运行

需要 Node.js 22.19 或更新版本，以及 pnpm。桌面运行还需要 Rust 和 Tauri 的平台依赖。

```powershell
pnpm install --frozen-lockfile
pnpm tauri dev
```

`pnpm tauri dev` 同时启动开发页面和本机服务。浏览器可访问终端显示的地址，并复用运行中的桌面宿主；单独运行 `pnpm dev` 只启动页面，正式功能仍需宿主在线。当前仅运行开发模式，不安装或发布程序。

## 使用

- 添加工作区，在模型设置中配置可用连接，选择模型与思考等级后发送消息。
- 会话配置可选择工具和项目指令范围；MCP 与本地扩展在设置中管理。
- 运行中可停止、排队后续消息；结果未知时使用原操作核对入口，保留原稿与下一稿。
- 文本、文件路径和图片通过材料准备后交付。已有会话正文由 Pi 的本地 JSONL 历史保存。
- 模型请求和工具可能访问外部服务或修改工作区；连接检查可能产生模型费用。

Windows 数据默认位于 `%LOCALAPPDATA%/Moon/models/`。密钥、MCP 环境与请求头可能包含敏感信息，请将数据目录保留在个人环境中。浏览器组件目录使用明确的示例服务。

同一页面服务的 `/ui-catalog/` 可浏览正式组件及示例状态，`/api-catalog/` 可浏览接口契约、模块归属并主动调用当前宿主。

开发规范、架构说明、审查报告与过程记录只在本地保留，不进入 Git。
