# Moon

本地 agent 应用，使用 React、Vite、shadcn/ui 和 Tauri。工作区、模型与会话配置保存于本机；对话和工具执行由 Pi SDK 提供。

## 运行

开发使用 Node.js 24.16.0、pnpm 11.24.0，以及 Rust 和 Tauri 的平台依赖。Windows 发行包自带 Node 运行时，使用者无需另行安装 Node。

```powershell
pnpm install --frozen-lockfile
pnpm tauri dev
```

`pnpm tauri dev` 同时启动开发页面和本机服务。浏览器可访问终端显示的地址，并复用运行中的桌面宿主；单独运行 `pnpm dev` 只启动页面，正式功能仍需宿主在线。当前仅运行开发模式，不安装或发布程序。

## 使用

- 添加工作区，在模型设置中配置可用连接，选择模型与思考等级后发送消息。
- 会话配置可选择工具和项目指令范围；MCP 与本地扩展在设置中管理。
- 运行中可停止、排队后续消息；结果未知时使用原操作核对入口，保留原稿与下一稿。
- 文本、文件路径和图片通过材料准备后交付。已有会话正文由 Pi 的本地 JSONL 历史保存。
- 模型请求和工具可能访问外部服务或修改工作区；连接检查可能产生模型费用。

Windows 安装时请选择用户目录之外、当前用户可写的位置，例如 `D:\Apps\Moon`。应用数据默认位于安装目录的 `data/`，包含会话、连接配置、材料、WebView 状态、日志和临时文件。开发模式使用项目内已忽略的 `.dev/moon/data/`；也可通过 `MOON_DATA_DIR` 指定开发数据根。

设置中的“数据与存储”可以查看或迁移数据目录。迁移会先保存并关闭相关资源，复制验证后启用新目录，保留旧副本；目标应是新的空目录。密钥、MCP 环境与请求头可能包含敏感信息，请将数据目录保留在当前用户的私人环境中。外部工作区文件和第三方程序自有数据仍由其各自管理。普通浏览器的用户配置由浏览器管理。

“关于与更新”从 GitHub 稳定 Release 检查版本，下载后校验发布签名，再由用户选择安装并重启。默认自动检查、手动下载；下载完成后退出应用需要重新下载。首次引入更新能力需手动安装新版本一次；开发模式不能安装正式更新。更新、重装和卸载均保留应用数据及外置数据目录。

同一页面服务的 `/ui-catalog/` 可浏览正式组件及示例状态，`/api-catalog/` 可浏览接口契约、模块归属并主动调用当前宿主。

开发规范、架构说明、审查报告与过程记录只在本地保留，不进入 Git。
